# Tasha’s Little Savings 📖✨

Diari nabung kecil-kecil milik Tasha: dua impian, satu halaman setiap hari.

Aplikasi pencatat tabungan personal bertema buku harian (*cozy diary journal*), dibangun dengan Next.js 16 (App Router) dan React 19.

## Fitur Utama

- **Target Impian**: Memantau progres tabungan iPad (Rp4.000.000) dan iPhone 11 Pro Max (Rp6.500.000).
- **Pencatatan Cepat**: Input nominal harian dengan opsi nominal cepat (Rp10rb, Rp35rb, Rp50rb, Rp100rb).
- **Streak & Kalender Mingguan**: Menghitung streak harian tanpa bolong dan menampilkan strip mingguan Senin s/d Minggu.
- **Milestone & Perayaan**: Efek animasi confetti saat berhasil menabung dan membuka milestone tabungan.
- **Tampilan Responsif**: Nyaman digunakan di handphone, tablet, hingga layar desktop.
- **Penyimpanan Lokal**: Seluruh data otomatis tersimpan di `localStorage` peramban pengguna.

## Menjalankan Secara Lokal

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) pada browser Anda.

## Tech Stack

- Next.js 16 (App Router)
- React 19
- CSS Variables & Responsive Reflow
